# 🎲 Introduction to parameter uncertainty

Hydrological models contain parameters that represent properties or processes
that are often **not known exactly**. Even after calibration, more than one
parameter set may be compatible with the available observations.

Parameter uncertainty analysis investigates how this incomplete knowledge of
parameter values propagates through a model and affects the simulated response.

The central question is therefore:

**If several parameter values are plausible, how uncertain are the resulting model predictions?**
