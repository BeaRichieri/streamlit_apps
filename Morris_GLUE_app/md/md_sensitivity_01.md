# 📊 Introduction to sensitivity analysis

Hydrological models translate assumptions about a system into simulated responses. Before using a model for interpretation or prediction, we need to understand **how model results depend on uncertain parameters** and **how uncertainty propagates into model predictions**.

This and the following section introduce the concepts using **simple synthetic examples**. The following course page, **Morris and GLUE application**, will transfer these ideas to a real LuKARS case study.
