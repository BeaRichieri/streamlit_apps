The interactive case-study allow the user to modify the model parameters and to inspect:

- observed and simulated spring discharge;
- hydrotope storage;
- matrix and conduit storage;
- slow infiltration from each hydrotope;
- rapid hydrotope flow;
- matrix-conduit exchange;
- matrix and conduit contributions to spring discharge;
- performance metrics for the simulated spring hydrograph.

Inspecting internal states and fluxes is essential because different parameter combinations can produce similar spring hydrographs.
