The available observations may not uniquely determine the unknown model parameters.

Different parameter combinations can sometimes produce very similar simulated discharge. This is one expression of **equifinality**. In addition, model parameters can compensate for one another, observations contain errors, and the model structure itself is an imperfect representation of the real system.

Consequently, a single parameter set with the best performance metric should not automatically be interpreted as the only physically plausible description of the catchment.
