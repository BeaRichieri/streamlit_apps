# 📊 Sobol' sensitivity analysis

Sobol' analysis is a **global variance-based sensitivity method**. Instead of
only ranking parameters, it asks how the variability of the model output can be
attributed to individual parameters and to interactions between parameters.

The key idea is to treat the model output $Y$ as a variable whose variance
$\mathrm{Var}(Y)$ is generated by uncertainty in the model parameters.
